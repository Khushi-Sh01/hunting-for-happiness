## Honest wording to preserve

| Use | Avoid |
| --- | --- |
| “Zen Mode invites you to lock your phone.” | “The web app forcibly locks your phone.” |
| “The phone keeps an accepted mission and draft offline.” | “Gemma runs offline inside this phone browser.” |
| “The local profile evaluates without a closed model API.” | “Everything in the Render/Atlas deployment stays on your device.” |
| “Local inference has no metered model API charge.” | “Every hosting and compute cost is zero.” |
| “Self-reported engagement earns XP.” | “The AI verified you physically completed the mission.” |
| “This is what happened in my real field test.” | A fabricated first-person outdoor story |
